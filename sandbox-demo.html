🔧 Integration Steps (Demo Flow)

1

Click "Connect TikTok" — OAuth Authorization

Directs user to TikTok's Sandbox OAuth flow. Requests scopes: user.info.basic, video.upload, video.publish.

Not Connected
2

Receive OAuth Callback — Token Exchange

The callback page receives the TikTok authorization code and exchanges it for an access token via the TikTok API. The token is stored securely and used for Content Posting.

No token yet — complete step 1 to get your access token.
3

Create TikTok Post — Content Posting API

Creates a post using the TikTok Content Posting API with pull_by_url media type. The video URL points to the media served by our Cloudflare Worker.

4

Webhook Receipt — Event Processing

The TikTok webhook at /webhook/tiktok receives event notifications and processes them. Events are stored in Supabase experiment_metrics table.
